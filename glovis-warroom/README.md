# GLOVIS WAR ROOM

글로벌 물류 리스크가 감지된 순간부터 고객 통보·사후분석까지, 하나의 사건이 6단계 파이프라인을 통과하는 AI 위기대응 관제실.

## 설치 및 실행

```bash
pip install -r requirements.txt
cp .env.example .env   # ANTHROPIC_API_KEY 입력 (없어도 실행됨)
streamlit run app.py
```

**API 키가 없어도 6개 탭 전부 캐시된 결과로 렌더됩니다.** 키를 넣으면 각 단계의 실행 버튼이 실제 LLM 호출로 결과를 덮어씁니다.

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `ANTHROPIC_API_KEY` | (없음) | 없으면 `fallback/`의 캐시된 결과로 동작 |
| `MODEL_NAME` | `claude-sonnet-5` | 사용할 모델 |

## 6단계 파이프라인

| 단계 | 내용 | 깊이 |
|---|---|---|
| ③ 감지 | 뉴스 20건 스캔 → 리스크 이벤트 추출 → 화물 50건 대조 → A/B/C 대체안 설계 | 깊게 |
| ① 검증 | 반대심문관이 3라운드 심문 후 PASS/CONDITIONAL/REJECT 판정 | 깊게 |
| ② 합의 | 4개 팀 순차 발언(for 루프) → 조정자가 합의안 도출 | 중간 |
| ⑤ 플레이북 | 파라미터 3개 → 실행 플레이북 마크다운 발행 | 얕게 |
| ⑥ 고객통보 | 톤이 다른 화주 메일 3종 + 예상 반응 | 얕게 |
| ④ 사후분석 | 누적 13건 원인 분류 → 반복 패턴·개선 제안 | 얕게 |

탭은 **순서와 무관하게 아무거나 눌러도 열립니다.** ③을 거치지 않고 ①을 먼저 눌러도 데모 화물(`GLVS2608-0417`)이 기본 선택됩니다.

## 데모 각본 (약 5분)

1. 앱 실행 → 사이드바에 사건 3건이 **이미 감지된 상태**
2. `🔴 로테르담 항만파업` 선택 → **③ 감지** 탭
3. `뉴스 스캔 실행` → 20건 중 물류 영향 기사만 필터링, 이벤트 카드 3장 렌더
4. **영향 화물 7건 / 전체 50건** → `GLVS2608-0417`(전기차·DDP·납기 촉박) 펼치기
5. `A안(항공 전환)으로 심의 요청` → **① 검증** 탭
6. `심문 시작` → 라운드1: 리드타임 수치의 출처와 기준일 추궁
7. 답변 입력 → 라운드2: **"UN3480 리튬이온 배터리 항공운송 시 위험물 신고와 SOC 30% 규정 대응이 준비되어 있습니까?"** ← 하이라이트
8. 답변 입력 → 라운드3: DDP 조건의 지체료 부담 주체 확인
9. → **CONDITIONAL 판정**, HIGH 미해결 2건
10. **② 합의** → `원탁회의 소집` → 4개 팀 토론 → **C안(복합운송) 합의**
11. **⑤ 플레이북** 발행 → **⑥ 고객메일 3종** → **④ 누적 패턴**
12. 마무리: **"이 사건 전체가 5분. 기존 프로세스로는 반나절."**

> 발표 시간이 모자라면 ①의 `심문 건너뛰고 판정 보기`로 바로 판정문을 띄웁니다.
> 사이드바 `데모 리셋`으로 언제든 초기 상태로 되돌립니다.

## 구조

```
app.py          Streamlit 진입점 (레이아웃 + 탭 라우팅만)
llm.py          LLM 호출 래퍼 + JSON 파서 + 폴백 로더
state.py        session_state 스키마, 시드 사건, 데이터 로더
prompts/        프롬프트 전량 (코드 수정 없이 튜닝 가능)
steps/          단계별 렌더 함수 6개
data/           shipments.csv(50) / routes.csv(30) / news_cache.json(20)
fallback/       API 키 없이도 6개 탭이 렌더되게 하는 캐시된 결과
```

### 데이터에 심어둔 함정

- `GLVS2608-0417` — 전기차 완성차, 특수화물코드 `UN3480`, DDP, ETA가 파업 기간과 정면 충돌. 반대심문의 하이라이트 근거.
- 납기 촉박 2건 — ETA와 납기일 차이 1~2일. SLA 위반 판정용.
- 간접영향 3건 — POD는 함부르크지만 T/S가 `NLRTM`. 직접/간접 구분 시연용.
- 노이즈 기사 13건 — 물류와 무관. "영향 없음"을 걸러내는 필터링 능력 시연용.

## 안전장치

- 각 단계는 **세션 결과 → 없으면 `fallback/` 로드** 순으로 렌더합니다. 폴백 사용 중에는 상단에 `📦 캐시된 결과 표시 중`만 조용히 표시됩니다.
- `llm.call_json`은 코드펜스 제거 → 파싱 → 1회 재시도 → 폴백 순으로 동작하며 **예외를 밖으로 던지지 않습니다.**
- 뉴스는 사전 캐싱된 JSON을 재생합니다. 실시간 크롤링 없음 — 데모 당일 네트워크·사내망 이슈로 발표가 날아가지 않습니다.
